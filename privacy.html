Privacy Policy — Sion Notes Uploader

Last updated: 2026-10-04

Sion Notes Uploader ("the tool") is a private tool used only by the owner of the YouTube channel @sion_why to upload that owner's own videos. It is not offered to the public and has no other users.

Use of YouTube API Services

The tool uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. Information handled through YouTube API Services is also subject to the Google Privacy Policy.

What data the tool accesses

  • An OAuth 2.0 token for the owner's own Google account, with the youtube.upload scope only.
  • The owner's own video files, titles and descriptions that the owner approves for upload.

The tool does not access, collect or store data about any other YouTube user, channel, viewer, comment or analytics account.

How the data is used and stored

The token is used only to upload approved videos to the owner's channel and set their title and description. It is stored on the owner's private home server, is not shared with or sold to anyone, and is not used for advertising or any other purpose.

Revoking access

The owner can revoke the tool's access at any time from the Google account security settings: https://myaccount.google.com/permissions. Revoking access stops all uploads immediately.

Data retention and deletion

  • The OAuth token is kept only while uploads are enabled. When access is revoked or the upload feature is turned off, the token is deleted from the server within 7 days.
  • The tool keeps no copies of data obtained from YouTube API Services. It only records, on the owner's own server, which of the owner's videos were uploaded and their video IDs.
  • To request deletion of any stored data, contact the owner through the channels below; it will be deleted within 7 days.

Contact

Questions about this policy can be sent through the channel's YouTube page or Instagram @sion.why.
